## Exam Format

### Question Types

1. **Multiple Choice** (60%)
   - Single correct answer
   - Covers theoretical knowledge

2. **Multiple Select** (20%)
   - Two or more correct answers
   - Tests deeper understanding

3. **Scenario-Based** (20%)
   - Real-world situations
   - Requires applied knowledge

### Sample Questions

#### SPCO Sample Question
**Question**: Which command verifies that SorobanPulse pods are running correctly?

A) `kubectl get nodes`  
B) `kubectl get pods -n soroban-pulse`  
C) `kubectl describe service soroban-pulse`  
D) `kubectl logs soroban-pulse`

**Answer**: B

#### SPCD Sample Question
**Question**: When implementing webhook retries, which HTTP status codes should trigger an automatic retry? (Select all that apply)

A) 200 OK  
B) 429 Too Many Requests  
C) 500 Internal Server Error  
D) 503 Service Unavailable  
E) 404 Not Found

**Answer**: B, C, D

#### SPCA Sample Question
**Scenario**: Your SorobanPulse deployment experiences high latency during peak hours. Database CPU is at 80%, and query response times have doubled. Which optimization strategies should you implement? (Select three)

A) Add read replicas  
B) Implement query result caching  
C) Increase pod memory limits  
D) Enable database connection pooling  
E) Add more application replicas  
F) Optimize slow queries with indexes

**Answer**: A, B, F

## Exam Day

### Before the Exam

**24 Hours Before**:
- Review key concepts
- Get adequate sleep
- Prepare test environment

**1 Hour Before**:
- Test camera and microphone
- Close all applications
- Clear desk area
- Have ID ready

### During the Exam

**Rules**:
- No external resources allowed
- No communication with others
- No leaving the camera view
- No phones or smart devices
- No writing materials (digital whiteboard provided)

**Tips**:
- Read questions carefully
- Flag difficult questions
- Manage your time (1.5-2 min per question)
- Review flagged questions
- Submit confidently

### After the Exam

**Immediate**:
- Preliminary pass/fail result
- Official score within 5 business days
- Certificate mailed within 2 weeks
- Digital badge issued immediately (if passed)

## Frequently Asked Questions

**Q: Can I take the exam if I don't have the prerequisite certification?**  
A: Yes, if you have equivalent professional experience documented.

**Q: What happens if I experience technical issues during the exam?**  
A: Contact the proctor immediately. Exam time will be paused while issues are resolved.

**Q: Are there any accommodations for disabilities?**  
A: Yes, we provide reasonable accommodations. Request during registration.

**Q: Can I use documentation during the exam?**  
A: No, exams are closed-book. All necessary information is provided in questions.

**Q: How long does it take to receive my certificate?**  
A: Digital badges are immediate upon passing. Physical certificates arrive within 2 weeks.

**Q: Do certifications expire?**  
A: Yes, all certifications are valid for 2 years and must be renewed.
